# mjml-rb 0.6.1 — 2026-11-05

Raise the minimum `nokogiri` dependency from 1.13 to 1.19.5 so installations
include the fixes from Nokogiri's latest security release. Newer Nokogiri
versions remain supported.

Nokogiri 1.19.5 fixes:

- A possible use-after-free when replacing attribute values on CRuby
  ([GHSA-3w22-6jfg-527w](https://github.com/sparklemotion/nokogiri/security/advisories/GHSA-3w22-6jfg-527w)).
- Mutation XSS involving HTML5 `noscript` serialization on CRuby
  ([GHSA-4p39-36wj-23h4](https://github.com/sparklemotion/nokogiri/security/advisories/GHSA-4p39-36wj-23h4)).
- A `NONET` bypass that could allow SSRF on JRuby
  ([GHSA-v995-44v6-5fqm](https://github.com/sparklemotion/nokogiri/security/advisories/GHSA-v995-44v6-5fqm)).

These are upstream Nokogiri fixes; this release does not change the MJML
compiler's rendering behavior. The MJML compatibility target remains **5.4.1**.
Ruby >= 3.3 and `css_parser` >= 1.17, < 4 are still required.

Update with `bundle update mjml-rb nokogiri`.

See the [Nokogiri 1.19.5 release notes](https://github.com/sparklemotion/nokogiri/releases/tag/v1.19.5)
for details and the HTML sanitization guidance for `noscript`.
